

\# ShopZone - E-commerce Website



ShopZone is an online shopping website developed using Python Flask and MySQL.



\## Technologies Used

\- Python

\- Flask

\- MySQL

\- HTML

\- CSS

\- JavaScript

\- Bootstrap

\- Razorpay



\## Features

\- User Registration and Login

\- Product Listing

\- Shopping Cart

\- Checkout

\- Online Payment

\- Order Management

\- Admin Dashboard

\- Product Management

\- User Management



\## How to Run



1\. Install required packages.

2\. Configure MySQL database.

3\. Add database details in the `.env` file.

4\. Run the application using:



&#x20;  `python app.py`
